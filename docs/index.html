Open Source · Pure Java · No native dependencies

Extract RAR archives
with pure Java.

unrar5j is a pure Java RAR extractor supporting RAR4 and RAR5 — AES-128/256 encryption, encrypted headers, solid and multi-volume archives, CRC32 and BLAKE2sp verification, zero native code.

Capabilities

Everything you need.
Nothing you don't.

A focused library that does one thing well — no bloat, no native binaries, no JNI.

📦

RAR4 & RAR5

Automatic format detection — the same API handles both RAR4 and RAR5 transparently, with no configuration needed.

🔐

AES Encryption

AES-128 (RAR4) and AES-256 (RAR5) decryption, including encrypted headers and file names.

🗂️

Multi-volume archives

Extraction across split .partNN.rar sets — part files are discovered and reassembled automatically.

🧩

Filters & solid archives

DELTA, E8, E8E9 (x86), and ARM filters supported, with correct handling of solid compression.

🛡️

CRC32 & BLAKE2sp

Integrity verification on every extracted file — CRC32, plus BLAKE2sp when the archive provides it.

☕

Pure Java

Runs anywhere Java 8+ runs. No JNI, no native binaries, no OS-specific setup. Deploy on any platform.

Quick Start

Up and running
in 60 seconds.

Add the dependency, write a few lines of Java. That's it.

Maven
Gradle
<dependency>
  <groupId>io.github.realburst</groupId>
  <artifactId>unrar5j</artifactId>
  <version>2.0.3</version>
</dependency>
implementation 'io.github.realburst:unrar5j:2.0.3'

// Extract an archive

ExtractionResult result =
    Unrar5j.extract(
        "archive.rar",
        "./output", null);

System.out.println("Extracted: "
    + result.successCount
    + "/" + result.totalFiles);
if (!result.isSuccess())
    result.print();

// Extract with a password

ExtractionResult result =
    Unrar5j.extract(
        "encrypted.rar",
        "./output",
        "mypassword");

// passwordStatus: 1=OK, 2=wrong
if (result.passwordStatus == 2)
    System.out.println("Wrong password");

// Extract a single file

ExtractionResult result =
    Unrar5j.extract(
        "archive.rar",
        "./output",
        null,
        "path/to/file.pdf");
result.print();

// Detect format & check encryption

int fmt = Unrar5j.detectFormat("a.rar");
// FORMAT_RAR4, FORMAT_RAR5,
// or FORMAT_UNKNOWN

if (Unrar5j.isEncrypted("a.rar")) {
    System.out.println(
        "Password required");
}

// Command line

# Extract to current directory (RAR4 or RAR5 auto-detected)
java -jar unrar5j.jar archive.rar

# Extract to a specific directory
java -jar unrar5j.jar archive.rar -o ./output

# Extract an encrypted archive
java -jar unrar5j.jar encrypted.rar -p mysecretpassword

# Extract a single file
java -jar unrar5j.jar archive.rar -f "path/to/document.pdf"

# Combine options
java -jar unrar5j.jar encrypted.rar -o ./output -p secret -f path/to/file.txt

Limitations

What's not supported.

Transparency matters. Here's what the library currently doesn't handle.

⚠️Read-only — creating or modifying archives is not supported
⚠️RAR4 PPMd compression method (0x35) is not supported
⚠️RAR4 VM filters (ITANIUM, RGB, AUDIO) are not supported
⚠️Archive comments and recovery records are skipped (not exposed)
